# 步骤 2：构建写作大纲与论述脉络

**目标：根据已明确的写作任务，选择、组织正文所需内容，并建立能够指导正文写作的论述主线。**

本工作单元给出基于材料的知识讲解类的完整工作方法；其他文稿按用途选用或调整，见[论述脉络质量规范与参考示例](../references/outline-quality.md)。开始构建脉络时读取该文件；完整知识讲解章节另参考[写作案例与对照](../references/writing-examples.md)。区分材料内容、正文范围、论述主线和最终脉络稿，避免将不同产物混为一谈。

**输出规范（适用于本工作单元的知识讲解类产物）：**各环节必须遵循下列模板的基本组成和组织形式；主题数量、层级深度、条目数量及具体措辞按实际内容确定，不照抄占位符。用户要求同时展示多个环节时，按 2.1—2.4 分别设置标题，保留每份产物的独立结构（可相应调整 Markdown 标题级别），不合并成总表，不以后一环节的产物替代前一环节。用户未要求展示的中间产物不必额外交付。其他文稿类型或用户明确指定不同格式时按实际任务调整。

## 2.1 材料内容识别与梳理

**目标：**识别参考材料的主要内容及组织结构，为后续选择内容提供基础。

工作方法：
1. 阅读材料，识别研究对象、范围及整体结构。
2. 沿用主要章节或主题，识别相对独立的知识项（概念、原理、性质、结论、方法等）；相关性质、实例与补充说明归入相应知识项。
3. 概括各主要部分及其基本关系。

**输出模板（必须保留三个组成部分）：**

```markdown
# 材料内容识别
## 1. 材料概述
[简短说明研究对象、主要内容及范围]
## 2. 内容结构
### [材料主要章节或主题]
- **[知识项名称]**：[该知识项包含的主要内容或讨论范围]。
## 3. 整体内容关系
[简述各主要部分分别研究什么及其基本关系]
```

材料概述与整体内容关系使用简短段落；内容结构按原材料主要章节或主题分组，使用“知识项名称＋范围说明”的列表，不以表格替代。材料中的特殊约定、条件及练习性质归入相关知识项或范围说明，不另列正文计算计划、写作作用或内容取舍。

覆盖主要内容，保持准确的术语、必要范围和来源性质；区分正式内容、补充内容及待证明的练习等。材料次级标题可以按识别粒度合并；不展开完整讲解，不提前进行目标文稿取舍。直接呈现材料内容，不重复任务状态或无关文件路径。

## 2.2 构建内容框架

**目标：**按写作目的选择正文需要包含的内容，并构建明确的上下位层级。

工作方法：
1. 根据文稿用途，从材料清单中选择正文需要讨论的内容。
2. 将研究同一对象、问题或方面的内容归入共同主题。
3. 按包含、从属与并列关系建立主要主题、次级主题及具体内容项。

**输出模板（必须采用分层大纲）：**

```markdown
# 文稿内容框架
## 1. [一级主题]
### 1.1 [二级主题]
- [知识项]
- [知识项]
### 1.2 [二级主题]
- [知识项]
## 2. [一级主题]
...
```

采用编号主题标题与下属知识项列表，必要时设置更深层级；内容没有合理的下级主题时可直接列知识项。不得用表格、扁平主题列表或解释性段落代替实际存在的层级。各层级具有实际归属关系；主题数与层级深度由内容决定，不机械复制材料目录。以简洁专业名称表示各项内容，不展开解释、定义、推导、计算或额外的主题任务说明。此框架是正文内容范围，不提前压缩为论述主线；对研究写作等场景可用问题、论点、证据、方法等内容项替代知识项。

## 2.3 构建论述主线（内容关系链）

**目标：**围绕写作目的，揭示主要内容的引入缘由、实质作用与相互关系，形成读者可以理解的整体论述路线。不是知识点排列、学习目标清单、压缩讲义或编写计划。

工作方法：
1. 确定各主题的主要问题或核心认识；以它决定主线范围。
2. 建立实质性内容关系。可从读者已有认识正向发展，也可从所需认识逆向追溯前提与中间过程。说明相关内容如何解决问题、自然派生、提供条件、支持论断或构成并行路径；不要求每项知识都有独立动机。
3. 补充必要依据。先回查原材料的定义、结论、证明和解释；可综合不同位置的知识。若关系缺失、引入依据不清或准确性存在实质疑问，且用户允许外部来源，按需查权威教材、专著、综述、原始研究或标准。区分原材料、综合认识与外部补充，记录新增实质性内容的来源；不扩大既定范围，不擅自改动约定。来源限制或工具不可用时，如实说明未能核实的实质问题。
4. 组织与提炼。依论述作用选择必要内容，补足逻辑桥梁，按真实的层级、递进、从属、并行及汇合关系组织。正文中的实例、性质、证明、公式与计算等若不承担主线作用，留在内容框架中；若本身是任务重点或必要条件，应保留。
5. 实际执行质量检查并修订，见[质量规范](../references/outline-quality.md)：问题回查、删除测试、跳跃测试、层级及科学条件检查。

**输出模板（必须按主题分条呈现）：**

```markdown
# 内容关系链
## 1. [主题名称]
**主要问题：**[本主题主要研究的问题或核心认识]
- [认识基础] → [具体关系或进一步需求] → [新认识]。
- [承接已有认识] → [进一步发展] → [新认识]。
- [共同问题]：
  - [第一条论述线索]。
  - [第二条论述线索]。
- [相关线索的联系]。
```

每个主要主题先写简洁的“主要问题”，再以列表分条表达实质关系；每条承担一个相对完整的论述推进或联系，有并行或从属线索时用嵌套条目表达，不将整个主题串成一段长关系链。根据实际关系组织连续、分支或并行结构，不要求每个主题都有分支或汇合，也不规定每条箭头数量。箭头连接的应是具体内容及真实关系，而不是省略了关键前提的术语接龙。新增外部实质内容附可追溯来源。以上为候选工作方法，质量以实际产物而非步骤形式判断。

## 2.4 形成脉络稿

**目标：**把已建立的论述主线组织为可供用户确认的自然、连贯的内容叙述。

依据关系链按主题组织，用具体对象和准确动词直接表达知识关系，交代必要缘由、作用、条件及承接；并行线索可在同一主题中分段。保留原材料恰当的专业措辞。不得为润色删去实质桥梁或引入新主线。发现关系链有缺陷先修正，不只是机械连接句子。本环节是整理操作，暂未经过独立行为验证。

**输出模板（编号主题与连续内容叙述）：**

```markdown
# 脉络稿
1. **[主题名称]：** [自然连贯地叙述本主题的认识发展过程及必要关系。]
2. **[主题名称]：** [承接相关认识，继续叙述。]
3. **[主题名称]：** [按实际关系叙述，必要时在同一主题内分段。]
```

按编号主题组织自然段落，不以关系链、知识清单或编写安排代替；不附加重复总览、学习目标、编写安排、计算计划、检查报告或执行状态。不设固定字数与主题数。对照 2.3 逐项核查必要的认识需求、条件、作用、分支及汇合关系是否保留；发现因表达转换而丢失的必要关系，直接补回。非主线细节可留在 2.2，不再次压缩已确认的必要关系。用户明确要求大纲、关系链或中间产物时，按要求展示；必要时随最终脉络简要保留正文范围与明确取舍，防止交接遗漏。最终确认的是正文内容方案及脉络。

## 材料与协作边界

四个子环节是工作分工，不是每步都必须向用户确认的审批流程。提交前同时检查各已展示产物的结构与内容职责；格式符合不能代替论述质量，最终脉络良好也不能抵消前面产物的结构缺失。用户只要求某环节时停在该环节；已有合格中间产物直接沿用。小范围修改按需压缩；修改现稿先审阅可访问原稿，明确保留和调整范围。没有材料或材料无法读取时不得假称已经核对。

原材料的事实、术语、条件与科学含义必须受到尊重，但可根据写作目的重组论述。对会改变核心内容、既定范围或关键结论的冲突，简明说明影响并交由用户决定；非阻断性核对事项留待正文，不假称已经解决。

速查稿以检索组织，题型总结以问题识别、条件和方法组织，文献阅读以作者问题、证据和局限组织，研究写作以论点、论据和结论边界组织。按任务选择相应形式，不强制套用知识讲解的箭头结构。

用户确认方案或明确按修订方案继续后进入第三步；仅提出调整时先修订。未进入主线但仍在正文范围的内容，第三步须落实；已明确舍弃的内容不得恢复。
