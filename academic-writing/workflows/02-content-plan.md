# 步骤 2：构建写作大纲与论述脉络

**目标：**从本次材料中选出必要内容，组织成能指导正文的认识路线；第二步交付的是**大纲及内容脉络**，不是正文，也不是仅列“准备讲什么”的写作清单。

## 从材料到脉络

1. **围绕核心认识取舍材料**：知识讲解类先确定每组要建立的主要认识，再从材料中选出让这一认识自然形成的概念、必要条件和真实联系。**讲义包含、正文重要，不等于必须进入第二步主线**；即使是重要定理、公式、实例或计算方法，若不承担主线中的必要作用，就留待正文展开。不能为了覆盖知识点而打断认识推进，也不能删去让关键关系成立的条件。若必要衔接在材料中没有讲清，先依据已有定义与条件推敲；**用户未限制来源时**，可按需检索可靠的课程资料或教材来核实和理解。外部资料只辅助解释，不扩大指定知识范围；存在实质差异时区分来源，不默默替换。用户要求仅依据指定材料时，不作外部检索。
2. **按理解目标组线索**：把服务同一问题、能够逐步利用前文认识的内容放在一起，而不是照搬材料目录。交代从已有认识到新认识的必要转折；同一主题中的相关分支可以并行，不必因材料分节或出现多种方法就各设一组，也不强制所有知识排成单一因果链。
3. **用自然语言直接讲清关系**：知识讲解类以读者能连续读懂的内容叙述为主体，不用“介绍／说明／联系 A 与 B”的写作指令代替解释。可参考“已有认识 → 新目标或直接派生 → 关键条件 → 用途”，但只取必要环节，不能为连贯而编造因果。**先说准，再说顺**：优先沿用来源中准确、自然的专业表述；用具体对象和清楚的动词交代作用，避免把“支撑、连接、汇合”等抽象词当成关系说明，也不要为压缩字数拼接过多概念。
4. **尊重任务边界**：修改已有文稿时须先审阅可访问的原稿，区分保留与调整范围；无法读取材料不得声称已核对。速查稿、题型总结、论文阅读与研究写作按其任务组织，不强制使用知识讲解类连续叙述。

## 输出与尺度

**知识讲解类的默认交付格式（除非用户另有要求）**：直接输出按认识路线分组的**少量编号主题段落**；每组用简短主题名带出一段直接陈述知识联系的自然叙述，确有并行线索时可在同组另起一段。以[认可范例](../references/writing-examples.md)的**内容取舍与认识推进**为参照，不设统一字数或主题数；保留关键条件，但不为覆盖细节而扩写成正文。

**只交付脉络本身**：不要默认另设“核心认识／贯穿问题／章节概述”，也不另附“计算侧重、例题选择、证明详略、写作建议、执行状态、文件路径”等安排清单。这些内部选材判断应落实在主题叙述中，而不是增加输出栏目。只有遇到会影响方案正确性、不能自行解决的**实质性材料冲突**时，才在末尾用一两句话说明问题及影响；非关键疑问留待正文核对。

速查、题型、论文阅读和研究写作按实际交付物组织，不套用上述主题段落形式与篇幅尺度。

**在“足以理解关系”处停止**：保留真实的前提、关键条件和概念之间的作用或转折；不要求每个概念单独设置动机，不要求证明关系为何成立的中间推导，也不提前列全定理、公式和解题步骤。精练是删去不推进认识的内容，不是把关系缩成“接着讲 A、联系 B”。知识讲解类的[来源到脉络的实例及正反对照](../references/writing-examples.md)用于校准这种尺度，不是必须复写的格式。

## 提交前

读一遍脉络：读者是否已经从内容陈述本身看出**为什么从这里转到那里**，还是只能看到作者计划介绍哪些术语？检查关键条件与关系是否忠于材料；需要时直接修订句子，避免缺环节或无谓展开，不输出自检报告。

用户确认方案或明确要求按修订方案继续后进入第三步；仅提出调整时先修订，不重复询问已定事项。
