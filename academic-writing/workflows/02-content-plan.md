# 步骤 2：构建内容方案与论述脉络

**任务：**依据已明确的写作目标和参考材料，充分理解知识，选择、组织内容，建立能够指导正文写作的论述脉络。

## 2.1 材料内容识别

阅读材料，识别研究对象、范围、主要知识及其组织关系。尊重术语、成立条件和来源性质，区分正式结论、补充内容和练习；此时充分理解材料，不提前按正文详略删减知识。

## 2.2 内容框架

根据文稿用途组织相关知识、必要支撑和层级，确定范围与重点。内容框架不等于论述主线或逐项必写清单；保留用户明确要求的必写内容。

## 2.3 内容关系链（按需）

复杂关系需要单独理清时，可参考[论述脉络参考](../references/outline-quality.md)，建立主要认识之间的关系。能够直接写好脉络时无需单独构建。

## 2.4 撰写脉络稿

阅读[通用写作规范](../references/writing-guidelines.md)及[脉络写作范例与对照](../references/writing-examples.md)中适用的完整范例；数学任务另参考[数学写作要求](../references/math-writing.md)。

依据写作目标、材料和内容框架，像熟悉本学科的教师向具有约定专业基础的读者讲解一样，用规范、准确、自然的专业语言，把主要知识及其内在逻辑讲清楚。脉络稿是一份可独立理解、简明而完整的主要认识的论述，不是编写安排或缩写的正文。具体细节留待正文。参考范例的实际效果，自主组织论述；研究写作等任务按各自用途组织。整体阅读并完善初稿，保留必要关系和已经恰当的表达。

**知识讲解类脉络稿的交付形式：**

```markdown
# 脉络稿
1. **[主题名称]：** [连续、自然的专业论述。]

   [同一主题下的另一相对完整的认识，按需分段。]
2. **[主题名称]：** [继续论述。]
```

## 交付与确认

默认仅交付完整脉络稿，供用户确认。材料识别、内容框架与可选关系链作为写作依据，不额外展示；明确要求查看中间产物时，按[规划中间产物格式](../references/planning-outputs.md)中的相应小节交付。存在实质内容取舍或来源冲突时说明待决事项；允许外部核实时，按需查阅权威来源，区分材料内容和外部补充。

用户确认后进入正文写作，保留内部框架、已确认脉络及必写约定。用户提出修改或希望进一步精炼时，直接在现稿基础上完善（可参考[可选精炼 Prompt](../references/planning-outputs.md#可选精炼)），无需重做规划；修订后确认，已明确授权继续的情况除外。正文的展开尺度由第三步决定。
