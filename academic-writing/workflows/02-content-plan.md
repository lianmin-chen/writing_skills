# 步骤 2：构建写作大纲与论述脉络

**目标：根据已明确的写作任务，选择、组织正文所需内容，并建立能够指导正文写作的论述主线。**

知识讲解类的常规产物是材料内容识别（2.1）、文稿内容框架（2.2）、最终脉络稿（2.4）。内容关系链（2.3）是按需使用的分析方法：关系复杂、需要与用户讨论主线或用户明确要求时，可以单独构建；能直接完成高质量脉络稿时不必先生成关系链。保留原编号便于已有任务和回测继续使用，不表示必须逐一执行四项。其他文稿按实际用途调整。

**输出规范：**用户要求展示的产物分别遵循相应模板的基本组织形式，主题数、层级、条目数和措辞由内容决定。一次交付多个环节时各自设置标题，保留独立结构，不合并成总表或相互替代。未要求展示的中间产物不额外交付。

## 2.1 材料内容识别与梳理

**目标：**识别参考材料的主要内容及组织结构，为后续选择内容提供基础。

工作方法：
1. 阅读材料，识别研究对象、范围及整体结构。
2. 沿用主要章节或主题，识别相对独立的知识项（概念、原理、性质、结论、方法等）；相关性质、实例与补充说明归入相应知识项。
3. 概括各主要部分及其基本关系。

**输出模板（必须保留三个组成部分）：**

```markdown
# 材料内容识别
## 1. 材料概述
[简短说明研究对象、主要内容及范围]
## 2. 内容结构
### [材料主要章节或主题]
- **[知识项名称]**：[该知识项包含的主要内容或讨论范围]。
## 3. 整体内容关系
[简述各主要部分分别研究什么及其基本关系]
```

材料概述与整体内容关系使用简短段落；内容结构按原材料主要章节或主题分组，使用“知识项名称＋范围说明”的列表，不以表格替代。材料中的特殊约定、条件及练习性质归入相关知识项或范围说明，不另列正文计算计划、写作作用或内容取舍。

覆盖主要内容，保持准确的术语、必要范围和来源性质；区分正式内容、补充内容及待证明的练习等。材料次级标题可以按识别粒度合并；不展开完整讲解，不提前进行目标文稿取舍。直接呈现材料内容，不重复任务状态或无关文件路径。

## 2.2 构建内容框架

**目标：**按写作目的选择正文需要包含的内容，并构建明确的上下位层级。

工作方法：
1. 根据文稿用途，从材料清单中选择正文需要讨论的内容。
2. 将研究同一对象、问题或方面的内容归入共同主题。
3. 按包含、从属与并列关系建立主要主题、次级主题及具体内容项。

**输出模板（必须采用分层大纲）：**

```markdown
# 文稿内容框架
## 1. [一级主题]
### 1.1 [二级主题]
- [知识项]
- [知识项]
### 1.2 [二级主题]
- [知识项]
## 2. [一级主题]
...
```

采用编号主题标题与下属知识项列表，必要时设置更深层级；内容没有合理的下级主题时可直接列知识项。不得用表格、扁平主题列表或解释性段落代替实际存在的层级。各层级具有实际归属关系；主题数与层级深度由内容决定，不机械复制材料目录。以简洁专业名称表示各项内容，不展开解释、定义、推导、计算或额外的主题任务说明。此框架是正文内容范围，不提前压缩为论述主线；对研究写作等场景可用问题、论点、证据、方法等内容项替代知识项。

## 2.3 内容关系链（可选方法）

需要单独理清或讨论主线时，围绕全文主要问题及各主题的作用，选择必要的知识关系，建立实际的认识或论证路线。可以正向发展、逆向追溯、组织并行或综合关系；不要求为每个知识点寻找独立动机。正文中的具体性质、公式、实例、证明和计算若不承担主线作用，留待正文。

**输出模板（仅在交付关系链时使用）：**

```markdown
# 内容关系链
## 1. [主题名称]
**主要问题：**[本主题主要问题或核心认识]
- [认识基础] → [具体关系] → [新认识]。
- [共同问题]：
  - [第一条线索]。
  - [第二条线索]。
```

每主题先写主要问题，再分条表达具体关系，有实际并行或从属关系时使用嵌套条目；不把整章连成长箭头或术语接龙。参考[论述脉络参考](../references/outline-quality.md)中的关系示例和诊断方法。关系链是帮助写作的工具，不是需要逐条翻译的文本模板。

## 2.4 撰写脉络稿

**目标：**形成一份具备约定基础的读者可以独立理解的、简明而完整的专业知识讲解，讲清本章主要认识及其内在逻辑，作为正文写作前的论述脉络。它不是编写安排，也不是缩写的正文。

写作前阅读[通用写作规范](../references/writing-guidelines.md)和[写作案例与对照](../references/writing-examples.md)中的适用完整范例及表达对照。数学任务另遵守[数学写作要求](../references/math-writing.md)。范例用于校准整体组织、论述尺度和具体专业表达；不模仿其题材、主题数、句式或固定篇幅。

**写作任务：**依据写作目标、材料和内容框架，像熟悉本学科的教师向具有约定专业基础的读者讲解一样，用规范、准确、自然的专业语言，把主要知识及其内在逻辑讲清楚。只讲必要的内容，把主要认识讲清楚；具体细节留待正文。已有关系链可以作为依据，但不必逐条转换；没有关系链时可直接撰写。初稿形成后整体阅读并完善，保留已经恰当的内容，必要时调整主题归属、论述顺序和表达，直接交付完善稿。无需另行报告编辑过程或反复重写。

**输出模板：**

```markdown
# 脉络稿
1. **[主题名称]：** [连续、自然的专业论述。]

   [同一主题下的另一相对完整的认识，按需分段。]
2. **[主题名称]：** [继续论述。]
```

不规定主题数、段落数、句式或字数。不要附加常规审查报告、学习目标、计算计划或重复总结。若同时交付内容框架、关系链与脉络稿，三者的正文范围及主线应相互一致；发现组织缺陷可直接修正尚未确认的方案，不要求先回到某个固定环节。用户明确要求只修改脉络稿时，直接基于现稿修改，不重新生成材料清单和大纲。

**完成条件：**最终内容方案及脉络能够指导正文写作；用户确认后进入第三步。

## 材料与协作边界

用户只要求某环节时停在该环节；已有合格产物直接沿用。没有材料或无法读取时不得假称已经核对。优先利用原材料的定义、结论和解释；关键关系不明确或科学含义有实质疑问，且用户允许外部资料时，按需核实权威来源，区分材料内容、综合认识与外部补充，标明新增实质内容的依据。

原材料的事实、术语、条件与科学含义必须受到尊重，但可根据写作目的重组论述。对会改变核心内容、既定范围或关键结论的冲突，简明说明影响并交由用户决定；非阻断性核对事项留待正文，不假称已经解决。

速查稿以检索组织，题型总结以问题识别、条件和方法组织，文献阅读以作者问题、证据和局限组织，研究写作以论点、论据和结论边界组织。按任务选择相应形式，不强制套用知识讲解的连续叙述或箭头结构。

用户确认方案或明确按修订方案继续后进入第三步；仅提出调整时先修订。未进入主线但仍在正文范围的内容，第三步须落实；已明确舍弃的内容不得恢复。
