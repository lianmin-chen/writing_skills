# 步骤 2：构建写作大纲与论述脉络

**目标：**根据已明确的写作任务和参考材料，确定主要内容、组织顺序及其真实联系，形成能直接指导正文的写作大纲；既不只列知识目录，也不提前写正文。

## 内容与脉络

1. **选择内容**：按文稿用途决定主要部分、必要内容和侧重，保留支持理解与论证的关键条件。不要照搬材料目录，也不因追求完整而平铺所有知识点。
2. **先核验关系，再安排顺序**：依据材料判断重要概念、结论与方法之间实际存在的定义、前提、推导、用途、对照或并列关系；检查不可缺少的条件及适用范围。**“基于 A 引入 B”不是关系已经讲清的证据**：如果 B 还依赖 C，或要回答一个新的问题，就不能省去 C 或问题本身。
3. **按需提供引入依据**：围绕各部分的核心问题，判断新内容能否由前文自然理解。已有结构足以定义或推出新内容时，直接承接即可；出现新的目标、问题或研究视角时，交代必要的缘由和桥梁；并行方法说明各自解决什么、为何分开讨论。只提供**最少但充分**的铺垫，不为每个术语编造独立动机，也不强行制造单线因果。
4. **适应具体操作**：新建或整理任务按目标与材料组织；修改现稿时先查看可访问的原稿，明确保留、补充、重组或删减的范围。未阅读原稿或材料，不得声称已对照或核实。组织方式服从具体文稿，不把知识讲解类的叙述强加给速查、题型、论文阅读或研究写作。

## 输出与边界

交付**可供用户审阅的写作大纲与论述脉络**。知识讲解类通常可用分组的连续段落，将已建立的认识自然发展为新的认识；其他类型可采用适合其用途的结构。写清内容本身的实际联系，少用“接着介绍”“重点讲解”等代替解释的写作安排语言。允许真正的分支，不强求每一句都从上一句派生。

**精练以不损害理解为界**：每句话承担必要的信息、联系或转折；删除冗余，但不能删去让关键新认识成立或自然出现的条件与桥梁。第二步确定论述路线及必要侧重，正式定义、完整证明、计算例题与正文表达留给第三步。

知识讲解类的完整认可范例及正反对照见[写作案例与对照](../references/writing-examples.md)；它校准判断品质，不是跨类型的固定模板。其他类型可以正常规划，其优质范例有待通过真实任务积累。

## 确认前自检

先形成脉络初稿，再对**重要概念的引入、关键结论的依据及相邻内容的逻辑桥梁**做一次定向检查，并据此**实际修订初稿**：若只给出了关系结论而缺少必要条件或使读者理解它的关键机制，补上最简明的解释；若已有内容足以自然承接，不额外制造动机。最后删除冗余，确认整段服务于核心问题。不要将脉络扩展为正式证明或正文，也不要展示自检过程。

用户确认大纲与脉络或明确要求按修订方案继续后，进入第三步；用户只提出调整意见时先修订，不重复询问已定事项。
