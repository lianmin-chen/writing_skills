# 步骤 2：构建写作大纲与论述脉络

**目标：**从本次材料中选出必要内容，组织成能指导正文的认识路线；第二步交付的是**大纲及内容脉络**，不是正文，也不是仅列“准备讲什么”的写作清单。

## 从材料到脉络

1. **提取有用的认识**：按文稿目的，从来源识别重要概念、必要条件、结论与方法，以及它们各自解决或支持的问题。将完整定义、证明、例题和次要细节留待正文，不因材料列有某项内容就必须放进脉络主线。
2. **按理解目标组线索**：把服务同一问题、能够逐步利用前文认识的内容放在一起，而不是照搬材料目录。明确每段已有的基础、下一项认识为何出现，以及产生了什么新能力或后续问题；不强制每节对应一段，也不强制所有知识排成单一因果链。
3. **直接写出内容关系**：知识讲解类以读者能连续读懂的概念叙述为主体，而不是“介绍／说明／联系 A 与 B”的编写指令。例如可以循“已有结构或能力 → 新目标／直接派生 → 关键条件或概念 → 结果与用途”组织，但**只取实际需要的环节**：直接派生的一句带过，并列方法说明共同问题与各自条件。必须写清决定新内容如何承接的真实关系，不能仅报出有关联的概念名。
4. **尊重任务边界**：修改已有文稿时须先审阅可访问的原稿，区分保留与调整范围；无法读取材料不得声称已核对。速查稿、题型总结、论文阅读与研究写作按其任务组织，不强制使用知识讲解类连续叙述。

## 输出与尺度

交付可供确认的**主要内容安排与论述脉络**。知识讲解类优先用少量主题及相应的自然叙述段落，**主题数按内容而定**；必要的证明取舍、例题或计算安排可简短附注，不能代替脉络段落。

**在“足以理解关系”处停止**：保留真实的前提、关键条件和概念之间的作用或转折；不要求每个概念单独设置动机，不要求证明关系为何成立的中间推导，也不提前列全定理、公式和解题步骤。精练是删去不推进认识的内容，不是把关系缩成“接着讲 A、联系 B”。知识讲解类的[来源到脉络的实例及正反对照](../references/writing-examples.md)用于校准这种尺度，不是必须复写的格式。

## 提交前

读一遍脉络：读者是否已经从内容陈述本身看出**为什么从这里转到那里**，还是只能看到作者计划介绍哪些术语？检查关键条件与关系是否忠于材料；需要时直接修订句子，避免缺环节或无谓展开，不输出自检报告。

用户确认方案或明确要求按修订方案继续后进入第三步；仅提出调整时先修订，不重复询问已定事项。
