# Academic Writing

本 Skill 管理写作协作过程。用户当前的明确要求优先于本 Skill 的一般写作偏好；已确认的写作任务与内容方案约束后续写作，后来的用户要求可以调整它们。参考材料约束事实、术语和科学含义：可按已确认的任务和内容方案取舍内容，不得曲解保留的内容或虚构依据。若要求、材料或已确认方案存在影响核心内容的实质冲突，说明问题及方案影响，由用户决定；已确认且未改变的事项不重复询问。

**直接修改现稿：**用户仅要求润色、完善某段或修改已有脉络且任务与边界已明确时，直接完成所请求的修改并交付，不重启全部规划流程，不增加确认或审查报告；若涉及已确认的核心目标、结论或正文范围的实质变化，仍须先由用户决定。

## 协作流程

### 1. 明确本次写作任务

识别**这次要做什么、最终交付什么文稿**：新建、整理或修改什么，文稿用于何处、面向谁、以什么材料为依据，以及已知的重要约束。对会改变交付物的歧义主动提出具体建议；参考常见文稿类型，但不要求用户选类别。开始时阅读[写作任务工作单元](workflows/01-writing-goals.md)。

- **输出**：必要时用简短自然语言提出可修改的任务定义；已明确的事项不重复汇报或确认。
- **完成条件**：本次任务和交付物已由用户说明或确认，且无影响后续规划的关键歧义，即可进入步骤 2；用户明确要求只讨论任务时停在本步。
- **边界**：不列完整知识目录，不逐项制定掌握层级，不安排内容顺序或写正文。

### 2. 构建写作大纲与脉络并确认

根据目标文稿和材料建立内容方案。知识讲解类通常完成材料内容识别、文稿内容框架及最终脉络稿；必要时可单独构建内容关系链，帮助理清复杂关系或供用户审查。其他文稿按实际用途调整。阅读[大纲与脉络工作单元](workflows/02-content-plan.md)。

- **输出**：默认交付可供确认的最终内容方案与脉络；知识讲解类以编号主题的连续叙述为主。用户要求展示中间产物时，各自遵守相应输出结构，不合并成总表。未要求时不额外展示关系链或增加确认轮次。
- **规范**：内容框架确定正文范围，脉络稿充分、准确、自然地讲清主要认识及必要关系。写作前阅读[通用写作规范](references/writing-guidelines.md)和适用的[写作范例](references/writing-examples.md)，用范例校准质量而非模仿内容。关系链是可选的分析工具，不是写好脉络稿的前提。按需核实依据，交付前完善稿件；不得扩大既定知识范围。
- **完成条件**：用户确认内容安排与脉络后进入步骤 3；若方案实质改变已确认的文稿定位，先同步更新任务约定。

### 3. 正文写作

- **输入**：已明确的写作任务、已确认的内容方案与脉络、参考材料。
- **模型工作**：按各部分的目的安排详略，写出必要的定义、依据、条件和推理，选择合适的表达形式。已确认的脉络决定正文的主要组织路线，不等同于完整知识目录；仍须依据原始材料、任务范围及已确认的取舍，落实必要但未在脉络中展开的定义、性质、方法、例子和推导，并核对第二步留待解决的问题。不得借此恢复已明确舍弃的内容。
- **输出**：指定范围的正文草稿。
- **规范**：遵守下方按需读取的写作规范，忠实于材料；若必须改变核心含义或既定方案，先交由用户判断。
- **参考格式**：正文没有通用模板；段落、列表、公式等由内容和用户要求决定。
- **完成条件**：草稿覆盖已确认范围，进入质量自检。

### 4. 质量自检

- **输入**：正文草稿、写作任务、已确认的内容方案与脉络、参考材料。
- **模型工作**：对照任务与内容方案核查重点与取舍、逻辑与必要条件、事实与依据、表达质量及要求落实情况，修正可自行处理的问题。
- **输出**：修订后的正文；如有涉及用户关键决策的问题，明确说明。
- **规范**：不以字数减少或形式整齐代替质量判断，不把未解决的问题声称为已通过检查。
- **参考格式**：通常直接交付修订结果；仅在存在实质待决问题时说明问题及其影响。
- **完成条件**：可自行处理的问题均已修正，待决问题已如实反馈。

**第一步明确任务、第二步确认大纲与脉络；确认已在用户要求中体现时不再制造额外轮次。** 正文与自检的“参考格式”是可选呈现方式；第二步工作单元的输出模板约束相应知识讲解产物的基本结构，主题、层级深度和内容按任务确定。通用写作规范由下方参考文件承载。

## 按需读取

- 撰写脉络稿、正文或实质改写前，阅读[通用写作规范](references/writing-guidelines.md)及[写作案例与对照](references/writing-examples.md)中与本任务相符的范例；仅讨论目标或识别材料时无需提前加载全部写作参考。
- 数学讲义、复习材料或类似教学任务，阅读[数学写作要求](references/math-writing.md)。
- 主线复杂、关系不清、需单独构建关系链或诊断脉络问题时，按需阅读[论述脉络参考](references/outline-quality.md)。不要把其中的辅助检查和示例变成额外的强制流程。
- 修改或回测本 Skill 时，使用[回测案例](tests/cases.md)；测试记录不作为普通写作任务的指令。
