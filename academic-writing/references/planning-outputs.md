# 规划中间产物格式与脉络精炼参考

仅在步骤 2 明确需要交付某项中间产物或进一步精炼已有脉络时，阅读相应小节。默认只交付脉络稿；中间分析不需要写成这些格式。各模板用于保持既有交付格式，不改变规划任务。

## 2.1 材料内容识别与梳理

**输出模板（需要交付 2.1 时，必须保留三个组成部分）：**

```markdown
# 材料内容识别
## 1. 材料概述
[简短说明研究对象、主要内容及范围]
## 2. 内容结构
### [材料主要章节或主题]
- **[知识项名称]**：[该知识项包含的主要内容或讨论范围]。
## 3. 整体内容关系
[简述各主要部分分别研究什么及其基本关系]
```

材料概述与整体内容关系使用简短段落；内容结构按原材料主要章节或主题分组，使用“知识项名称＋范围说明”的列表，不以表格替代。材料中的特殊约定、条件及练习性质归入相关知识项或范围说明，不另列正文计算计划、写作作用或内容取舍。

覆盖主要内容，保持准确的术语、必要范围和来源性质；区分正式内容、补充内容及待证明的练习等。材料次级标题可以按识别粒度合并；不展开完整讲解，不提前进行目标文稿取舍。直接呈现材料内容，不重复任务状态或无关文件路径。

## 2.2 构建内容框架

**输出模板（需要交付 2.2 时，必须采用分层大纲）：**

```markdown
# 文稿内容框架
## 1. [一级主题]
### 1.1 [二级主题]
- [知识项]
- [知识项]
### 1.2 [二级主题]
- [知识项]
## 2. [一级主题]
...
```

采用编号主题标题与下属知识项列表，必要时设置更深层级；内容没有合理的下级主题时可直接列知识项。不得用表格、扁平主题列表或解释性段落代替实际存在的层级。各层级具有实际归属关系；主题数与层级深度由内容决定，不机械复制材料目录。以简洁专业名称表示各项内容，不展开解释、定义、推导、计算或额外的主题任务说明。此框架明确正文的知识范围与层级，充分保留与任务有关的知识及必要支撑，不提前压缩为论述主线或依据正文默认详略删减。用户明确要求的必写内容或必写深度要保留；对研究写作等场景可用问题、论点、证据、方法等内容项替代知识项。

## 2.3 内容关系链

**输出模板（仅在交付关系链时使用）：**

```markdown
# 内容关系链
## 1. [主题名称]
**主要问题：**[本主题主要问题或核心认识]
- [认识基础] → [具体关系] → [新认识]。
- [共同问题]：
  - [第一条线索]。
  - [第二条线索]。
```

每主题先写主要问题，再分条表达具体关系，有实际并行或从属关系时使用嵌套条目；不把整章连成长箭头或术语接龙。参考[论述脉络参考](outline-quality.md)中的关系示例和诊断方法。关系链是帮助写作的工具，不是需要逐条翻译的文本模板。

## 可选精炼

**备选执行 Prompt：进一步精炼脉络稿**

用户选择进一步精炼，或已明确要求同类修改时，直接采用以下指令执行；无需用户复制或再次确认是否执行：

> 请在现有脉络稿的基础上进一步完善，使其更加简明、准确、自然，符合正文写作前的脉络稿定位。保留已经恰当的内容和主要知识之间的实质关系，适当合并重复或过度展开的论述，推敲专业措辞，并补足必要的逻辑承接与科学条件。只讲必要的内容，把主要认识讲清楚；不承担主线作用的公式、证明、实例和计算细节留待正文，不因精炼而删减已确定的正文范围。直接给出修改后的完整脉络稿，不重新执行材料识别、内容框架或关系链构建，不进入正文写作。

这是一项针对已有合格初稿的可选编辑操作，不代替首次交付前应有的质量自检。精炼不是缩减字数的任务，不要求达到某个固定篇幅；优先保留现稿中已经充分、准确、自然的表达。若用户仅要求修改指定部分或明确要求保持原有结构，则以其具体要求为准；发现实质性范围或核心认识需要变更时，按协作边界处理。

修改后交付完整脉络稿，保留原内容框架及正文范围；若原方案存在实质待决事项，简要说明。仅选择精炼不等于确认修订稿或授权撰写正文；等待用户确认，除非用户已经明确要求修订后直接继续正文。已明确确认方案、指定只完成规划或只修改现稿时，不机械追加选择菜单、重复确认或擅自进入正文。
