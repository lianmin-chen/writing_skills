# 论述脉络质量规范与参考示例

适用于专业文稿的内容规划与脉络审查。它补充 [第二步工作单元](../workflows/02-content-plan.md)，不增加新的强制协作阶段，也不替代正文规范。以下是设计规范与自编示例；矩阵论第一章格式回归及第二章跨章节规划已在用户交互中基本通过，第二章单独撰写脉络的补充指令观察到改善。不能据此认定各条规范的独立贡献或新组合版本已通过测试。

## 1. 目标与产物边界

好的论述脉络使具备约定基础的读者能够沿着文稿的主要问题，理解主要内容为何出现、实际说明什么，以及如何与其他内容联系。其质量不由知识点数量、箭头数量、篇幅或固定结构决定。

| 产物 | 决定什么 | 典型单位 |
| --- | --- | --- |
| 材料清单 | 材料包含什么 | 内容名称与范围 |
| 文稿内容框架 | 正文写什么 | 分层内容项 |
| 内容关系链 | 如何建立主要认识或论证 | 具有具体含义的内容关系 |
| 脉络稿 | 如何充分、准确、自然地叙述主线 | 围绕相对完整的论述目的组织的段落，或适合任务的结构 |

主线不是完整正文。未进入主线的知识，若仍在正文范围内，应在正文中落实。

## 2. 基本原则

- 目的导向：以文稿用途和主要问题决定重点与取舍。
- 读者导向：以已有认识为基础，提供理解新内容所需的语境。
- 科学准确：以真实知识关系、证据及适用条件为依据，不编造因果或动机。
- 逻辑完整：保留必要的中间认识、限制和关系；知识存在联系不等于它足以支撑论述。
- 结构合理：按共同目标归组，区分整体与局部、递进与并行、主线与支线。
- 详略适当：提供能够理解主要思想的最小充分解释；不把证明、实例、算法细节一概排除，也不将其一概纳入。

## 3. 怎样建立实质性关系

一条关系要能回答具体问题：前面的认识提供什么基础？新内容因何需要或如何自然产生？它解决了什么、得到了什么、能够支持什么后续认识？

| 关系 | 可用的组织方式 | 避免 |
| --- | --- | --- |
| 需求与解决 | 明确目标，再说明条件或方法的作用 | 先列定义，再泛称重要 |
| 自然派生 | 基于已有运算、事实或概念直接得到新内容 | 强行创造动机 |
| 局限与扩展 | 说明原有认识无法处理的问题及扩展带来的能力 | 不说明局限就引入概念 |
| 条件与结论 | 保留实际前提和结果 | 将相关性当因果、将定理当定义前提 |
| 共同目标与并行路径 | 说明各路径处理的情形、共同点与区别 | 把并行方法写成彼此导致 |
| 论点与依据 | 说明证据支持的观察或结论及边界 | 证据堆砌或超出证据断言 |
| 综合与汇合 | 明确多个认识如何相接或统一 | 仅说“相互联系” |

不要求逐条分类或报告内部推理；顺序也不一定是数学证明顺序、教材目录或研究历史。直接说清真实关系即可。

## 4. 质量检查：实际修订而不是自评分

先守住事实、来源和用户决策边界；重要科学错误或未解决的实质冲突不能用其他优点抵消。

| 检查项 | 合格表现 | 具体修订操作 |
| --- | --- | --- |
| 目标一致性 | 主线回答主要问题 | 问题回查：对照每个主题提出的问题，补足尚未回答的部分 |
| 关系明确、逻辑完整 | 读者不必自行补关键前提 | 跳跃测试：相邻内容能否说明具体承接？缺失需求、条件、机制或结论时补齐到必要尺度 |
| 内容必要性 | 每项内容有主线功能 | 删除测试：移去候选细节后目标仍完整则留正文；缺了会改变科学含义或使关系突兀则保留 |
| 层级与整体性 | 上位问题统摄相关线索 | 将同一目标下的内容归组，识别并行、从属和汇合；不为追求连贯强编单线 |
| 科学准确性 | 条件、术语、证据范围与关系真实 | 回查来源及必要条件；区分定义、定理、证明、例子和作者观点 |
| 表达清晰性 | 直接叙述实质内容 | 将“介绍 A、说明 B 的关系”等元话语改为具体关系；减少重复，不删必要解释 |
| 正文可执行性 | 主线与正文范围共同指导写作 | 对照内容框架，确保留待正文的必要内容未被误删；用户明确舍弃的内容不恢复 |

内部修订后直接交付结果；只报告需要用户决策的实质问题。质量检查不要求给出长篇评分表。

## 5. 按需补充依据

原材料明确关系时直接利用；关系散见定义、性质和证明时综合材料；若关键桥梁缺失或准确性不确定，且来源限制允许，定位具体疑问后查阅权威资料。成熟知识优先教材、专著及大学课程材料；前沿问题优先原始论文、专业综述或相关标准。核实定义、符号、适用条件及与原材料的差异。记录新增实质性内容的出处（作者、题名、章节或可访问链接），不得编造引用或声称读过不可访问的文献。根据定义作出的可核实推论不必假托外部作者；教学上的组织方案不是原作者的历史动机。外部资料不足、用户限制来源或工具不可用时如实处理；扩大任务范围及实质冲突交用户决定。

## 6. 参考示例：同样的原则，不同的论述结构

以下示例输入为自包含的教学或假设材料，正反例均为本 Skill 自编的示范，而非引用原著。重点在选择与组织，不复用固定措辞；完整矩阵论章节的用户认可脉络见 [writing-examples.md](writing-examples.md)。

### A. 知识讲解：从线性运算到基与坐标（概念递进）

**材料与目标：**有限维线性空间有加法与数乘、线性组合、张成、线性无关、基、维数、坐标及换基。正文还需要自然基与计算实例。读者已有基础线性代数，目标是解释抽象向量怎样得到可计算的表示。

**反例：** 线性运算 → 零元与负元 → 基的定义 → 自然基实例及数域对维数的影响 → 坐标及换基公式。

问题：知识顺序不等于认识顺序；遗漏表示需求以及两个条件的作用，提前展开实例。

**正例（关系链）：**
- 加法与数乘 → 线性组合 → 用一些向量表示其他向量。
- 希望用有限的一组向量唯一地表示全空间 → 张成保证每个向量都能被表示；线性无关保证表示唯一 → 构成基。
- 基向量个数确定维数，唯一的表示系数构成坐标 → 坐标映射是一一的线性对应 → 抽象线性问题转为坐标计算。
- 基不唯一 → 同一向量可有不同坐标 → 过渡矩阵联系两种表示。

自然基、具体公式和计算仍在正文范围；有限维及唯一性的条件不可省略。

### B. 知识讲解：子空间的组合与分解（从问题到条件）

**材料与目标：**非空子集对原有加法和数乘封闭即为子空间，向量组可生成子空间；交、和、维数公式、直和、零空间及列空间。目标是说明怎样确定部分结构并实现全空间的分解。

**反例：** 子空间 → 零空间、列空间及秩 → 交和维数公式 → 直和判据 → 多子空间推广。

问题：将应用与进一步性质挤入主线，缺少引入和的缘由，也未回答全空间分解的条件。

**正例（关系链）：**
- 研究全空间中一部分向量 → 非空且对原运算封闭 → 子空间；给定集合可判定，给定向量组可取其全部线性组合构造。
- 研究组合 → 交保留共有部分；并集一般不封闭 → 寻找包含两者的最小子空间 → 和。
- 和允许分解但不保证唯一 → 两个子空间交仅含零向量时分解唯一 → 直和；和还等于全空间时，才得到全空间的直和分解。

不需在脉络中证明直和等价定理。若用户改为讲解维数公式或矩阵的核与像，相应内容则应进入主线。

### C. 知识讲解：内积的坐标计算（分支与汇合）

**材料与目标：**一般基提供坐标但不一定保持标准内积；标准正交基简化坐标与内积；Gram–Schmidt 从基构造标准正交基；度量矩阵记录基向量间内积；标准正交基下矩阵为单位矩阵。目标是解释如何将内积转入坐标计算。

**反例：** 正交组线性无关 → Gram–Schmidt 计算步骤 → 标准正交基 → 正定 Hermite 矩阵 → 合同关系 → 度量矩阵。

问题：将算法和性质排列成单线，未说明两种计算情形和共同问题。

**正例（关系链）：**
- 已有坐标表示保留线性结构，但一般基下不能直接用坐标的标准内积反映原空间内积 → 如何利用坐标计算几何关系？
  - 可以选择基：标准正交基简化内积与坐标计算 → Gram–Schmidt 提供从一般基构造它的方法。
  - 使用给定的基：度量矩阵记录基向量之间的内积 → 得到相应的坐标表达。
- 两条线索相接：标准正交基下，度量矩阵为单位矩阵。

不将一般基与标准正交基写成互相排斥的数学理论；这是共同目标下两种处理情形。证明正交补分解时先建立正交基也可以合理，不能仅因与本例顺序不同判为失败。

### D. 知识讲解：数值求根（并行方法与适用条件）

**材料与目标：**连续函数在闭区间两端异号时至少有一个零点；二分法保持异号区间、逐次缩小范围。Newton 法使用导数的切线近似迭代；需要适当的求导条件、非零导数和初值，不保证任意初值收敛。目标为解释两种方法的基本思想。

**反例：** 介绍中值定理、二分法、Newton 公式、程序和收敛速度，再总结。

**正例：** 求根的共同问题是寻找函数值为零的点。若已知连续函数的异号区间，可利用零点存在性，在每次二分后保留仍含零点的异号区间，逐步缩小搜索范围。若能利用导数，则可在当前点用切线近似函数，以切线零点更新估计；这就是 Newton 法的思路，其适用与收敛取决于条件及初值。两者是不同的近似路径，不由其中一种必然推出另一种。

评价：保留两种方法的认识基础、作用及边界；不把程序或比较结论提前强加给主线。

### E. 非数学知识讲解：疫苗与免疫记忆（机制与边界）

**材料与目标（自包含简化材料）：**疫苗向免疫系统提供抗原或其产生信息，诱导适应性免疫反应及免疫记忆；再次遇到相关抗原时，记忆反应可能更快或更有效。保护效果受疫苗、病原体变化、时间及个体等因素影响，不必然完全阻止感染。目标为解释基本原理，不写临床建议。

**反例：** 疫苗分类 → 抗体 → T 细胞 → 接种次数 → 疫苗能防止感染。

**正例：** 希望免疫系统在真正遇到病原体之前形成针对性准备 → 疫苗提供抗原或其产生信息 → 诱导适应性免疫反应并形成免疫记忆 → 再次遇到相关抗原时可能更快或更有效地应答 → 降低某些感染或严重疾病风险，但保护程度受多种条件影响，并不等于保证不感染。

评价：组织机制链，保留概率和适用边界，不为说明机制而扩写分类、免疫细胞细节或接种建议。本例材料用于说明写作方法，具体医学论断另需依正式任务核实。

### F. 研究写作：结果与讨论（主张与证据）

**材料与目标（假设数据）：**同一测试集、同一误差指标（越小越好），方法 A 为 0.18，基线 B 为 0.22；未提供重复实验、显著性检验或其他测试集。拟写结果与讨论。

**反例：** A 误差更小 → A 显著优于 B → 证明 A 在所有场景有效 → 介绍应用前景。

**正例：** 研究问题是 A 在给定测试条件下能否降低误差。相同测试集与指标使报告结果可比较 → A 的观测误差比 B 低 0.04 → 支持在本测试条件下 A 的观测表现更好 → 缺少重复实验和跨数据集证据，尚不能判断统计显著性或泛化优势 → 将可能解释明确标为待验证假设。

评价：主线由证据能够支持的主张决定，不将知识讲解的概念引入模板套到研究论证中。

### G. 同一内容因用途改变而组织不同

采用示例 A、B、C 的数学材料：
- 系统知识讲解：围绕研究对象、表示、结构分解及几何计算的认识关系组织。
- 考前速查：按需要检索的定义、适用条件、公式与易混判据组织；不要求完整的概念动机链。
- 题型总结：按判定子空间、求生成空间、判断直和、换基与计算内积等问题组织，联系识别条件、方法及易错点。
- 专门说明 Cauchy–Schwarz 与三角不等式：此时不等式是核心桥梁，不应因全章脉络的示例省略它；先定义由内积产生的长度，再用不等式支持三角不等式。

评价：内容重要性随写作任务变化。示例是参照，不是待复现答案。

## 8. 脉络稿的写作质量与正反例

关系链负责确定主要认识及必要关系，脉络稿负责把它们写成具备约定基础的读者可以独立理解的专业叙述。精炼是选择必要内容并把它说清楚，不是将若干箭头压缩成一句话，也不是把全部正文知识缩写一次。

写作时按认识发展组织句子和段落：给出必要的语境与对象，直接写出关系、条件、作用及结果；一个主题中的不同论述任务可分别成段。主题之间优先利用真实的承接、对照、推广或综合关系，不为流畅强造因果。逐项回查必要关系是否实际呈现；发现不足可返回主线修订。以下示例沿用本文件已有的自包含材料，不规定固定句式、主题数、段落数或字数。

### H. 充分表达，而不是压缩必要桥梁（示例 A）

**反例：** 线性空间通过基、维数与坐标实现抽象问题的计算，过渡矩阵联系不同表示。

问题：句子简短，但读者无法理解基为什么具有表示能力，张成和线性无关的作用也消失了。

**正例：** 有了加法与数乘，就可以通过线性组合用一些向量表示其他向量。对于有限维空间，我们希望选取有限的一组向量，使整个空间中的向量都能被唯一表示：张成性保证表示存在，线性无关性保证表示唯一。同时满足这两个条件的向量组就是基，其向量个数给出维数，而表示系数构成坐标。由于基的选取并不唯一，同一向量可以有不同的坐标，因此还需要通过过渡矩阵联系这些表示。

评价：补全表示需求与两个条件的具体作用；并不需要展开求基或过渡矩阵的计算。

### I. 直接呈现实质关系，而非总结存在联系（示例 B）

**反例：** 子空间的交与和具有重要联系，直和进一步体现了空间分解的思想。

**正例：** 两个子空间的交保留共有部分，而并集一般不再封闭。为了得到同时包含两者的最小子空间，需要取它们的和。和空间中的向量可以分解为来自两个子空间的向量之和，但分解未必唯一；当两个子空间的交仅含零向量时，分解才唯一，得到直和。如果它们的和还等于全空间，就得到了全空间的直和分解。

评价：直接说明并集的局限、和的作用、唯一性的条件以及全空间分解的额外条件；不以“体现联系”替代实际联系。

### J. 按认识任务分段，并建立并行路径的实际联系（示例 C）

**反例：** 标准正交基使计算简单，Gram–Schmidt 可以构造标准正交基，度量矩阵记录内积并在标准正交基下等于单位矩阵。这些内容共同解决了内积计算问题。

**正例：** 坐标表示使抽象向量能够转化为数字进行计算，但一般基下的坐标标准内积并不一定等于原空间的内积。因此，还需要研究怎样利用坐标计算内积。

一种方式是选取便于计算的基。标准正交基使原空间的内积直接等于坐标的标准内积，Gram–Schmidt 正交化提供了从一般基构造标准正交基的方法。

如果必须使用给定的一般基，则需要通过度量矩阵记录基向量之间的内积，建立原空间内积的坐标表达。两种方式并不矛盾：标准正交基下的度量矩阵正是单位矩阵。

评价：先建立共同问题，再区分可选基与给定基的论述任务；用分段体现关系而不是固定三段要求。直接呈现两条路线如何相接。

### K. 在专业叙述中保留适用条件（示例 D）

**反例：** 二分法和 Newton 法都可以逐步求出函数的零点，后者利用导数提高收敛速度。

**正例：** 若已知连续函数在一个闭区间两端异号，就知道区间内至少存在一个零点。二分法利用这一条件，在每次二分后保留仍具有异号端点的区间（若中点恰为零点则可停止），逐步缩小搜索范围。

另一种思路是利用导数，在当前估计处用切线近似函数，并以切线的零点更新估计。这就是 Newton 法的基本思想；迭代需要满足相应的求导条件且当前导数非零，其收敛还取决于函数性质和初值。

评价：两条路径分别由实际条件引出，不承诺 Newton 法总能收敛或总比二分法快。具体迭代公式、误差估计与程序留待正文，除非写作任务以这些为重点。

### L. 非数学研究叙述：结论与证据边界（示例 F）

**反例：** 方法 A 的误差显著低于 B，体现出良好的泛化能力，后续将分析其原因与局限。

**正例：** 为考察方法 A 能否降低预测误差，在同一测试集上使用相同指标与基线 B 进行比较。A 的观测误差为 0.18，B 为 0.22，因此在本次测试条件下，A 的观测误差更低。但现有材料没有报告重复实验、显著性检验或其他测试集，尚不足以判断这一差异的统计显著性或跨场景泛化优势。

评价：具体说出数据支持的认识及不能支持的结论，不以笼统的“分析局限”代替边界，也不将教学叙述的概念动机形式强加于研究文稿。
