# 写作案例与对照

这些例子用于区分写作任务与内容方案，并以完整成稿和具体修改对照校准专业写作质量。优先阅读与当前交付物相符的示例，学习内容取舍、论述组织和专业表达的实际效果，而非模仿主题数、句式或篇幅。数学事实与范围仍以当前来源为准。第一章与第二章的完整范例来自用户反馈；第二章为对话中认可稿的科学表述微调版，其他自编示例不声称已获用户认可。

## 第一步：同一份材料可以有不同交付物

**输入**：用户提供《矩阵论》讲义第一章，但尚未说明希望形成哪一种文稿。可依据用途提出不同定位：

- **复习讲稿（新建撰写／知识讲解）**：“以讲义第一章为依据，编写可独立阅读的系统复习讲稿，用解释帮助读者理解主要概念与方法，而非逐页缩写。”
- **考前速查稿（整理提炼／复习整理）**：“从第一章提炼关键定义、成立条件、公式及方法，形成便于临考检索的简明笔记，而非系统讲解。”
- **题型总结（整理提炼／题型与方法）**：“以讲义中的常见问题和方法为依据，按题型归纳适用条件、解法与易错点，而非按知识章节逐项解释。”

第一步要确定**选择哪种成品及其用途**，不是同时设计三份内容方案；类型已经明确时，无需把三类备选再次展示给用户。

**文献阅读笔记**：“阅读指定论文，整理研究问题、方法、主要结果与作者给出的证据和局限，明确区分论文主张与笔记者的分析。”它不同于撰写新的研究论文。

**现有文稿修改**：“在保留原稿研究结论和证据边界的前提下，重组讨论部分以改善论证清晰度。”这是修改完善任务，不是另起一篇新论文。

## 第二步优秀示例：矩阵论第一章系统复习解释稿

**适用场景**：知识讲解类，面向矩阵论考试复习的章节解释稿。这里展示的是**正文写作之前的内容脉络**，不是定稿正文；新建稿与修改已有讲稿都可参考其判断方式，但修改任务还需对照现稿。

以下完整保留用户认可的示例。示例开头“按当前 Skill……”是当时的背景说明，**新的实际交付直接从编号主题开始**；主题数、具体术语不作为其他任务的固定答案：

按当前 Skill，第一章可以围绕三个主题建立脉络。下面是**正文写作前的脉络稿**：

1. **线性空间：向量、矩阵和多项式的形式不同，却都可以进行加法与数乘。为了统一研究这些对象的线性关系，我们抽取两种运算共同遵循的规律，定义线性空间**。有了线性运算，就可以用**线性组合**表示其他向量。对于本章讨论的有限维空间，我们希望从空间中的大量向量里找到有限的一组，仍能表示整个空间：张成性保证每个向量都能被表示，线性无关性保证表示唯一，同时满足这两个条件的向量组就是**基**。基向量的个数是**维数**，表示向量的系数是它在这组基下的**坐标**，于是抽象向量可以转化为具体的数字进行计算。然而，同一空间可以选取不同的基，同一向量的坐标也会随之改变，因此还需要研究**基变换与坐标变换**，用过渡矩阵建立两组表示之间的联系。
2. **子空间：研究整个线性空间时，我们也会遇到其中满足特定条件的一部分向量。若这部分向量组成的非空集合**对原有加法与数乘封闭，它就保留了线性空间的结构，可以作为**子空间**单独研究。由此有两项不同的工作：面对一个由条件限定的集合，需要判定它是否为子空间；面对一组已知向量，则可以取其所有线性组合，构造**生成子空间**。得到子空间后，还需知道它们如何组合。两个子空间的**交**保留共有部分；并集一般不再封闭，若要得到同时包含两者的最小子空间，就取它们的**和**。和空间中的向量可以写成来自两个子空间的向量之和，但这种分解未必唯一；当两个子空间的交仅含零向量时，分解才唯一，这便是**直和**。若它们的和还等于全空间，就得到全空间的直和分解。
3. **内积空间：在线性空间中，向量之间只有线性结构，距离、夹角等几何性质尚未得到刻画，因此引入内积**。内积使长度、距离与正交关系有了定义；借助正交关系得到的**正交补**，又把前面的子空间直和分解与几何性质联系起来。

   此后的内容分为两条相关线索。一条关注**怎样选择便于计算的基**：标准正交基使向量的表示和内积计算更简单，Gram–Schmidt 正交化说明如何从一般基构造这样的基。另一条关注**在已有的基下怎样计算内积**：不能对任意基都直接用坐标的标准内积计算原空间的内积，因此需要用**度量矩阵**记录基向量之间的内积，得到相应的坐标表达。两条线索最终相接：当选取标准正交基时，度量矩阵就是单位矩阵。

**输出尺度**：上面的三条主题脉络就是本轮第二步的完整交付；无需再增设全章总览、计算计划、例题清单或执行状态说明。第三条包含两条计算路线，但仍归在同一个内积主题下。

### 这份脉络如何从原讲义构建出来

讲义第一章原有四节：**1.1 线性空间定义、1.2 基与坐标、1.3 子空间、1.4 内积空间**。上面的三条脉络不是删掉一节或复制目录，而是按**每组内容共同回答的问题**重新组织。

1. **把 1.1 与 1.2 连成“从线性结构到表示”**。来源先列举向量、矩阵、函数等对象，再抽象加法与数乘；接下来定义基、维数、坐标及换基。选用的解释顺序是：不同对象为何可以统一研究 → 线性组合提供表示能力 → 希望有限且唯一地表示全空间 → 张成性和无关性共同确定基 → 维数、坐标使计算成为可能 → 基不唯一，因而需要换基关系。保留每个转折的**内容依据**，但不搬运运算公理、证明和坐标例题。
2. **将 1.3 组织成“研究部分、组合部分、唯一分解”**。非空与封闭性为子空间提供条件；“检验已有集合”和“用向量组生成集合”是不同工作；交、并、和回答怎样组合，其中并一般不封闭，所以以和来包含两者；和可以分解却不一定唯一，再以零交引出直和和全空间分解。讲义另有维数公式及证明，但它不是这条概念主线必经的引入环节，可在正文中完整处理。**这里交代零交与唯一性的关系即可，不要求在第二步写出分解差落在交空间的证明。**
3. **把 1.4 写成“几何结构 + 两条计算路线”**。来源明确指出线性结构不能刻画长度、夹角等，故引入内积；长度、距离、正交是内积之上的直接展开，正交补又连接前文的直和。计算内积时，构造标准正交基与在给定一般基下使用度量矩阵是**同一目标下的不同处理条件**，而非先后因果；在标准正交基下度量矩阵成为单位矩阵。Cauchy–Schwarz 不等式虽属于本章重要正文内容，却不必为了“列齐知识点”插入概念主线。

### 同一章的取舍对照：重要不等于应进入主线

**主线需要的内容**：线性运算为什么引出统一的线性空间、线性组合怎样通向有限且唯一的表示；子空间怎样判定与生成、交与和为什么通向分解唯一性的直和；内积为什么补充几何关系，以及正交基与度量矩阵各自如何处理内积计算。这些环节一旦省略，下一步认识就会突兀。

**重要但通常留待正文的内容**：零空间、列空间及秩的计算，交与和的维数公式，Cauchy–Schwarz 不等式与勾股关系，正交组无关性的推导，以及 Gram–Schmidt 的逐步计算。它们在讲义和考试复习中有价值，但不是上述概念引入链条的必经环节。后续一次回测把这些内容几乎全部放进三四段脉络，导致句句有知识，却成为压缩的知识点清单。

**不是禁止出现**：如果某个结果是用户指定的理解重点，或省去它会使当前主题中的关键联系无法成立，就应保留；判断依据是它在**这份脉络中的解释作用**，而不是是否属于某个预设的知识点黑名单。内积的几何含义与两种计算路径也可归入同一主题，不必为每一种方法另开一级标题。

### 实际失效对照：有逻辑的知识概述仍可能不是认识脉络

一次用户反馈中的实际输出已建立概念联系，却在引入基时先陈述定义条件，加入过渡矩阵的构造、零空间和列空间、维数公式、Cauchy–Schwarz 与 Gram–Schmidt 的实现原理，并把内积的几何意义和坐标计算分为两个并列主题；同时没有明确子空间的非空条件和全空间直和分解的条件。以下从该输出节选，和上面的认可范例作对照（省略号表示节选）。这不是对相关知识的禁止清单。

| 实际表达或处理 | 应学习的判断 |
| --- | --- |
| “在有限维空间中，一组向量既能张成全空间、又线性无关，才构成基；前者保证能够表示，后者保证表示唯一。” | 先呈现有限且唯一表示整个空间的需求，再引出存在性、唯一性的条件与基，使读者理解为何需要这些概念，而非先给定义再解释。 |
| “它的列是新基向量在旧基下的坐标” | 此处只需交代同一向量因换基而坐标不同，过渡矩阵联系两种表示；具体矩阵构造留给正文。 |
| “矩阵的零空间和列空间分别提供这两种认识子空间的典型入口” | 在全章认识路线中，先说明为什么研究空间的一部分，以及非空、封闭的条件；典型实例可在正文落实。 |
| “维数公式说明交中重复计入的部分如何影响和空间的维数” | 维数关系重要但不是这条分解路线的必要转折；必须先保留零交对应唯一分解、和等于全空间才得到全空间直和分解的区别。 |
| “Gram–Schmidt 方法从线性无关向量组逐步去除已有方向上的分量……” | 当前只需说明它能够从一般基构造标准正交基；投影、保持生成空间和单位化等实现细节留给正文。 |
| 将内积几何与内积计算拆成两个一级主题 | 两者同属在原有线性结构上引入内积后的认识；计算内部又有选取便于计算的基与在给定基下计算的两种情形。以共同目标与从属关系确定层级，不按内容功能机械分块。 |

例如，若写作目标改为“为什么内积定义的长度满足三角不等式”，Cauchy–Schwarz 就可能成为主线中的必要依据；若目标是 Gram–Schmidt 的算法解释，其具体操作关系也可能需要出现在脉络中。没有固定的知识点禁用名单或主题数。

**可迁移的生成方式**：以写作目的确定核心认识和主题层级；以核心认识决定内容取舍；以认识的发展决定论述顺序；以必要性决定解释深度。先有整体目标，再判断局部内容是基础、需求、必要条件、直接派生还是并行方法；直接陈述真实关系，在引入理由、作用及后续联系已足够清楚时停止。可参考“已有什么 → 还需要什么／自然得到什么 → 用什么条件或概念完成 → 因而能做什么”，但不是每组必填四格，也不要求每个术语都有独立动机。

**辨别是否写成脉络**：

- 仅有安排：“接着说明交与和，联系零交和直和，讲解分解唯一性。”——读者只知道作者打算讲什么。
- 有内容推进：“和空间中的向量可分解成两个子空间的向量之和，但分解未必唯一；若两者交仅含零向量，分解便唯一，得到直和。”——已经交代分解、问题与条件，足以指导正文；不必提前写证明。

这套判断针对**知识讲解类**，并不要求考前速查、题型总结、论文阅读笔记或研究论文模仿三段式概念串讲。范例的主题数、字数、术语和句法都不是硬模板；每次以实际来源与写作任务为准。

## 第二步参考：研究结果的证据边界

**情境（虚构数据）**：研究者要撰写某实验结果段落，已提供同一设置下 A 的误差为 0.18、B 的误差为 0.22，指标越低越好；没有重复实验或显著性检验结果。

该任务的内容方案应准确报告指标与数值，说明只能观察到 A 的数值较低，不能凭空断言统计显著、因果机制或普遍优越。这是后续内容选择与论证深度的判断，**不是要求第一步为“结果段落”列教学式知识目标**。

## 第二步优秀示例：矩阵论第二章系统复习解释稿

**用途：**与第一章相同，面向已有线性代数基础的读者，解释主要认识如何发展；正文仍需落实材料中的定义、性质、公式、实例和方法。以下保留用户反复认可的四主题稿的核心组织与表达，作少量数学术语和条件的澄清。不是独立重新核对讲义后形成的唯一答案。

1. **线性变换与矩阵表示：** 第一章通过基与坐标，将有限维空间中的抽象向量转化为具体的坐标表示。本章进一步研究向量之间的映射，其中保持加法与数乘的映射称为线性映射。由于任意向量都可以表示为基向量的线性组合，而线性映射保持这种组合关系，因此只要知道定义域一组基向量的像，就能够确定整个映射。将这些像在陪域所选基下的坐标按列组成矩阵，便可以通过矩阵与坐标向量的乘积计算向量的像。

   对于同一空间上的线性变换，其核与像分别由映为零的向量和所有可能的像组成，在坐标表示中分别对应表示矩阵的零空间与列空间；变换的复合等运算也可以转化为矩阵运算。然而，同一变换在不同基下可以具有不同的矩阵表示，因此需要通过矩阵相似建立不同表示之间的联系。如果进一步研究不同线性空间之间的线性映射，则可以分别选取定义域与陪域的基建立矩阵表示，两端分别换基时，相应矩阵之间满足更一般的等价关系。

2. **不变子空间与特征结构：** 虽然矩阵使线性变换能够进行计算，但为了进一步理解变换的结构，我们希望通过研究空间的各个部分来理解整体。如果一个子空间中的向量经过变换后仍属于该子空间，就可以将变换限制在其中，这样的子空间称为不变子空间。当全空间能够分解为两个不变子空间的直和时，整体变换便可以通过各子空间上的限制变换研究；选取与这种分解相适应的基，变换的矩阵就具有分块对角形式。

   在此基础上，我们希望找到变换作用特别简单的不变部分。如果一个非零向量经过变换后只是乘以一个标量，就得到特征值与特征向量；属于同一特征值的全部特征向量连同零向量构成特征子空间，变换在其中仅表现为数乘。借助矩阵表示，线性变换的特征问题可以转化为矩阵的特征问题。不同特征值对应的特征子空间之和是直和；当这些子空间的和等于全空间时，整个变换就可以分解为各特征子空间上的数乘变换。

3. **正交变换与酉变换：** 当线性空间具有内积结构时，我们不仅可以研究变换对线性关系的影响，还可以研究它是否改变向量的几何性质。保持内积的线性变换能够保持长度、距离和正交关系，在实内积空间和复内积空间中分别称为正交变换和酉变换。

   为了利用矩阵判定变换是否保持这些几何性质，可以选取标准正交基。由于保持内积等价于将标准正交基映为标准正交基，而基向量的像的坐标又构成表示矩阵的各列，因此这种几何条件可以转化为矩阵列向量的标准正交条件，从而建立正交变换与正交矩阵、酉变换与酉矩阵之间的联系。

4. **投影变换：** 前面研究不变子空间时，利用空间的直和分解将整体变换转化为各部分上的变换。反过来，已有的全空间直和分解也可以用来构造一种特殊的线性变换：将向量唯一地分解为属于两个子空间的分量，保留其中一个分量而消去另一个分量，这就是投影。被保留的子空间是投影的像空间，被消去的子空间是其核空间。对于非平凡投影，它们分别是特征值 1 和 0 对应的特征子空间。

   由于投影后的向量再次经过投影时保持不变，因此投影矩阵具有幂等性；反过来，幂等矩阵也确定一个投影。当直和分解中的两个子空间相互正交时，就得到正交投影。在标准正交基下，正交投影矩阵不仅幂等，而且是 Hermite 矩阵。正交投影还能够给出目标子空间中距离原向量最近的点，从而将空间分解与几何逼近联系起来。已知直和两侧的基可以构造一般投影矩阵，而对于正交投影，只需要目标子空间的一组基就可以完成构造。

### 全章编辑判断

矩阵表示回答抽象变换如何计算，因此不同空间之间的映射是表示方法的推广，适宜与矩阵表示归组，而非仅因原讲义位置放在投影主题。随后从计算转向结构分析，再加入内积研究几何性质；最后利用已有分解构造投影，与不变子空间的分析路线形成实际对应。主题间承接本身传达专业认识，而不是添上衔接词。

正文范围内的具体映射判定、换基公式、基向量不变性检验、几何与代数重数、旋转或镜像实例、投影的矩阵构造式及最近点证明等，均不因重要就需要在这个尺度逐一展开。相反，矩阵特征问题的对应、投影的双向幂等刻画及其核像与特征子空间的实际关系、正交投影的基条件和两类构造依据承担必要的主线作用，不能因精简而全部省略。若任务改为讲解某项具体算法，应重新判断取舍。

## 专业表达与编辑判断：同一知识的实际对照

以下从第二章的多轮实际输出与认可稿提取。左侧并非全部属于事实错误；有些只是没有选中当前论述需要表达的认识。右侧示范更恰当的表达及原因。学习判断，不要求逐句模仿，也不把任何词语设为绝对禁用。

### 1. 引入研究对象，而不是泛称变化

**原表达：** 第一章用基和坐标表示线性空间中的向量；现在进一步研究向量怎样变化。线性变换保持加法与数乘，因此也保持线性组合。

**改进：** 第一章通过基与坐标，将抽象向量转化为具体的坐标表示。本章进一步研究向量之间的映射，其中保持加法与数乘的映射称为线性映射。

**判断：** 在章际承接处，前章实现的坐标化是本章的认识基础；“向量之间的映射”准确指明新对象，再以运算保持条件限定线性映射。原文的“怎样变化”没有指明研究对象，且直接开始陈述尚未引入的概念的性质。若写的是基的定义，则唯一坐标可能恰是重点。

### 2. 完整而直接地表达专业关系

**原表达：** 一个向量由基向量怎样表示，决定了它的像由这些基向量的像怎样表示。线性性使基成为认识整个变换的入口。

**改进：** 由于任意向量都可以表示为基向量的线性组合，而线性变换保持这种组合关系，因此只要知道一组基向量的像，就能够确定整个变换。

**判断：** 直接用“线性组合”“像”“确定变换”说明两个依据及具体结论。原句绕口，后一句用修辞概括而未增加认识；改进不追求最短，而是让完整关系自然可读。

### 3. 新概念的实际研究缘由

**原表达：** 为了看清变换怎样作用于空间，可以寻找在变换下保持封闭的子空间，即不变子空间。

**改进：** 虽然矩阵使线性变换能够进行计算，但为了进一步理解变换的结构，我们希望通过研究空间的各个部分来理解整体。如果一个子空间中的向量经过变换后仍属于该子空间，就可以将变换限制在其中，这样的子空间称为不变子空间。

**判断：** 从计算转向结构研究，讲清为什么需要研究部分、什么条件使部分可以独立研究。“封闭”容易与对运算封闭或拓扑闭集混淆。这里不需要补上不变性判定步骤才能使引入成立。

### 4. 依据具体对应建立关系

**原表达：** 标准正交基还使几何条件转化为简洁的矩阵条件：相应矩阵的列向量必须标准正交。

**改进：** 为了利用矩阵判定变换是否保持这些几何性质，可以选取标准正交基。由于保持内积等价于将标准正交基映为标准正交基，而基向量的像的坐标又构成表示矩阵的各列，因此这种几何条件可以转化为矩阵列向量的标准正交条件。

**判断：** 在有限维同空间变换的语境中，调用前文建立的“基向量的像的坐标构成矩阵的列”，读者由此理解为什么几何条件能转化为代数判据。只给结论或添加具体矩阵公式并不能代替这条桥梁。

### 5. 主题承接传达新的认识

**原表达：** 直和分解使投影有了明确含义。投影把空间分解具体化。

**改进：** 前面研究不变子空间时，利用空间的直和分解将整体变换转化为各部分上的变换。反过来，已有的空间直和分解也可以用来构造一种特殊的线性变换。

**判断：** 明确给定变换时分析其结构与给定空间分解时构造变换的区别和联系。原句虽通顺，却没有说出关系。不同的合理组织也可以成立，不强求全文每个主题都有这一类反转。

### 6. 精确给出关系与科学条件

**原表达：** 其特征值只可能为 0 或 1，相应的特征子空间分别与零空间、像空间相联系。正交投影既是幂等矩阵，也是 Hermite 矩阵。

**改进：** 对于非平凡投影，其像空间和核空间分别是特征值 1 和 0 对应的特征子空间。在标准正交基下，正交投影矩阵不仅幂等，而且是 Hermite 矩阵。

**判断：** “相联系”未说清具体对应；零投影或恒等投影不具有两个不同特征值。区分变换与其矩阵，保留矩阵判据的基条件。类似的专业限定应直接融入论述，而非补上一段抽象审查说明。

### 7. 说明能够做什么，避免正文安排代替认识

**原表达：** 相应的矩阵条件和求法可在正文中进一步展开。

**改进：** 已知直和两侧的基可以构造一般投影矩阵，而对于正交投影，只需要目标子空间的一组基就可以完成构造。

**判断：** 原句只报告写作计划，改进具体说明两类方法的输入条件及区别；不需要把构造公式也展开。若正文安排本身是用户要求的交付物，则可以保留安排说明。

### 使用方式

完整范例校准成稿尺度与组织，局部对照校准具体编辑判断。写作时面对知识与读者，正常进行专业讲解；已有初稿则在其基础上完善，不必逐句复现范例、不必增加审查产物。相同知识可有多种准确、自然的表达，范例不是评分答案。非数学任务选用相应的论证、证据及表达方式。
