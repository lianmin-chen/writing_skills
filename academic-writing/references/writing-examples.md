# 写作案例与对照

这些例子用于**区分写作任务与内容方案**，并校准后续数学内容的逻辑表达。不是固定回答模板；数学材料的事实与范围仍以当前来源为准。

## 第一步：同一份材料可以有不同交付物

**输入**：用户提供《矩阵论》讲义第一章，但尚未说明希望形成哪一种文稿。可依据用途提出不同定位：

- **复习讲稿（新建撰写／知识讲解）**：“以讲义第一章为依据，编写可独立阅读的系统复习讲稿，用解释帮助读者理解主要概念与方法，而非逐页缩写。”
- **考前速查稿（整理提炼／复习整理）**：“从第一章提炼关键定义、成立条件、公式及方法，形成便于临考检索的简明笔记，而非系统讲解。”
- **题型总结（整理提炼／题型与方法）**：“以讲义中的常见问题和方法为依据，按题型归纳适用条件、解法与易错点，而非按知识章节逐项解释。”

第一步要确定**选择哪种成品及其用途**，不是同时设计三份内容方案；类型已经明确时，无需把三类备选再次展示给用户。

**文献阅读笔记**：“阅读指定论文，整理研究问题、方法、主要结果与作者给出的证据和局限，明确区分论文主张与笔记者的分析。”它不同于撰写新的研究论文。

**现有文稿修改**：“在保留原稿研究结论和证据边界的前提下，重组讨论部分以改善论证清晰度。”这是修改完善任务，不是另起一篇新论文。

## 第二步优秀示例：矩阵论第一章系统复习解释稿

**适用场景**：知识讲解类，面向矩阵论考试复习的章节解释稿。这里展示的是**正文写作之前的内容脉络**，不是定稿正文；新建稿与修改已有讲稿都可参考其判断方式，但修改任务还需对照现稿。

以下完整保留用户认可的示例，不把其篇幅、三个主题或术语作为其他任务的强制要求：

按当前 Skill，第一章可以围绕三个主题建立脉络。下面是**正文写作前的脉络稿**：

1. **线性空间：向量、矩阵和多项式的形式不同，却都可以进行加法与数乘。为了统一研究这些对象的线性关系，我们抽取两种运算共同遵循的规律，定义线性空间**。有了线性运算，就可以用**线性组合**表示其他向量。对于本章讨论的有限维空间，我们希望从空间中的大量向量里找到有限的一组，仍能表示整个空间：张成性保证每个向量都能被表示，线性无关性保证表示唯一，同时满足这两个条件的向量组就是**基**。基向量的个数是**维数**，表示向量的系数是它在这组基下的**坐标**，于是抽象向量可以转化为具体的数字进行计算。然而，同一空间可以选取不同的基，同一向量的坐标也会随之改变，因此还需要研究**基变换与坐标变换**，用过渡矩阵建立两组表示之间的联系。
2. **子空间：研究整个线性空间时，我们也会遇到其中满足特定条件的一部分向量。若这部分向量组成的非空集合**对原有加法与数乘封闭，它就保留了线性空间的结构，可以作为**子空间**单独研究。由此有两项不同的工作：面对一个由条件限定的集合，需要判定它是否为子空间；面对一组已知向量，则可以取其所有线性组合，构造**生成子空间**。得到子空间后，还需知道它们如何组合。两个子空间的**交**保留共有部分；并集一般不再封闭，若要得到同时包含两者的最小子空间，就取它们的**和**。和空间中的向量可以写成来自两个子空间的向量之和，但这种分解未必唯一；当两个子空间的交仅含零向量时，分解才唯一，这便是**直和**。若它们的和还等于全空间，就得到全空间的直和分解。
3. **内积空间：在线性空间中，向量之间只有线性结构，距离、夹角等几何性质尚未得到刻画，因此引入内积**。内积使长度、距离与正交关系有了定义；借助正交关系得到的**正交补**，又把前面的子空间直和分解与几何性质联系起来。

   此后的内容分为两条相关线索。一条关注**怎样选择便于计算的基**：标准正交基使向量的表示和内积计算更简单，Gram–Schmidt 正交化说明如何从一般基构造这样的基。另一条关注**在已有的基下怎样计算内积**：不能对任意基都直接用坐标的标准内积计算原空间的内积，因此需要用**度量矩阵**记录基向量之间的内积，得到相应的坐标表达。两条线索最终相接：当选取标准正交基时，度量矩阵就是单位矩阵。

**输出尺度**：上面的三条主题脉络就是本轮第二步的完整交付；无需再增设全章总览、计算计划、例题清单或执行状态说明。第三条包含两条计算路线，但仍归在同一个内积主题下。

### 这份脉络如何从原讲义构建出来

讲义第一章原有四节：**1.1 线性空间定义、1.2 基与坐标、1.3 子空间、1.4 内积空间**。上面的三条脉络不是删掉一节或复制目录，而是按**每组内容共同回答的问题**重新组织。

1. **把 1.1 与 1.2 连成“从线性结构到表示”**。来源先列举向量、矩阵、函数等对象，再抽象加法与数乘；接下来定义基、维数、坐标及换基。选用的解释顺序是：不同对象为何可以统一研究 → 线性组合提供表示能力 → 希望有限且唯一地表示全空间 → 张成性和无关性共同确定基 → 维数、坐标使计算成为可能 → 基不唯一，因而需要换基关系。保留每个转折的**内容依据**，但不搬运运算公理、证明和坐标例题。
2. **将 1.3 组织成“研究部分、组合部分、唯一分解”**。非空与封闭性为子空间提供条件；“检验已有集合”和“用向量组生成集合”是不同工作；交、并、和回答怎样组合，其中并一般不封闭，所以以和来包含两者；和可以分解却不一定唯一，再以零交引出直和和全空间分解。讲义另有维数公式及证明，但它不是这条概念主线必经的引入环节，可在正文中完整处理。**这里交代零交与唯一性的关系即可，不要求在第二步写出分解差落在交空间的证明。**
3. **把 1.4 写成“几何结构 + 两条计算路线”**。来源明确指出线性结构不能刻画长度、夹角等，故引入内积；长度、距离、正交是内积之上的直接展开，正交补又连接前文的直和。计算内积时，构造标准正交基与在给定一般基下使用度量矩阵是**同一目标下的不同处理条件**，而非先后因果；在标准正交基下度量矩阵成为单位矩阵。Cauchy–Schwarz 不等式虽属于本章重要正文内容，却不必为了“列齐知识点”插入概念主线。

**可迁移的生成方式**：从材料提取重要概念及条件，判断它们在本稿中是基础、产生的能力、待解决的问题、直接派生还是并行方法；围绕共同的理解目标分组，然后**把这些真实关系直接说给读者听**。可参考“已有什么 → 还需要什么／自然得到什么 → 用什么条件或概念完成 → 因而能做什么”，但不是每组必填四格，也不是每个术语都要独立动机。

**辨别是否写成脉络**：

- 仅有安排：“接着说明交与和，联系零交和直和，讲解分解唯一性。”——读者只知道作者打算讲什么。
- 有内容推进：“和空间中的向量可分解成两个子空间的向量之和，但分解未必唯一；若两者交仅含零向量，分解便唯一，得到直和。”——已经交代分解、问题与条件，足以指导正文；不必提前写证明。

这套判断针对**知识讲解类**，并不要求考前速查、题型总结、论文阅读笔记或研究论文模仿三段式概念串讲。范例的主题数、字数、术语和句法都不是硬模板；每次以实际来源与写作任务为准。

## 第二步参考：研究结果的证据边界

**情境（虚构数据）**：研究者要撰写某实验结果段落，已提供同一设置下 A 的误差为 0.18、B 的误差为 0.22，指标越低越好；没有重复实验或显著性检验结果。

该任务的内容方案应准确报告指标与数值，说明只能观察到 A 的数值较低，不能凭空断言统计显著、因果机制或普遍优越。这是后续内容选择与论证深度的判断，**不是要求第一步为“结果段落”列教学式知识目标**。
