# 专业写作编辑对照

以下对照来自原 knowledge-outline 与 knowledge-summary 的实际输出、编辑讨论和认可范例。原表达有些并非事实错误，而是对当前论述任务不够恰当。学习具体判断及修改理由，不复用固定措辞，不把相同知识的其他合理表达判为错误。

## 一、认识发展与专业关系

### 1. 引入研究对象，而不是泛称变化

**原表达：** 第一章用基和坐标表示线性空间中的向量；现在进一步研究向量怎样变化。线性变换保持加法与数乘，因此也保持线性组合。

**改进：** 第一章通过基与坐标，将抽象向量转化为具体的坐标表示。本章进一步研究向量之间的映射，其中保持加法与数乘的映射称为线性映射。

**判断：** 在章际承接处，前章实现的坐标化是本章的认识基础；“向量之间的映射”准确指明新对象，再以运算保持条件限定线性映射。原文的“怎样变化”没有指明研究对象，且直接开始陈述尚未引入的概念的性质。若写的是基的定义，则唯一坐标可能恰是重点。

### 2. 完整而直接地表达专业关系

**原表达：** 一个向量由基向量怎样表示，决定了它的像由这些基向量的像怎样表示。线性性使基成为认识整个变换的入口。

**改进：** 由于任意向量都可以表示为基向量的线性组合，而线性变换保持这种组合关系，因此只要知道一组基向量的像，就能够确定整个变换。

**判断：** 直接用“线性组合”“像”“确定变换”说明两个依据及具体结论。原句绕口，后一句用修辞概括而未增加认识；改进不追求最短，而是让完整关系自然可读。

### 3. 新概念的实际研究缘由

**原表达：** 为了看清变换怎样作用于空间，可以寻找在变换下保持封闭的子空间，即不变子空间。

**改进：** 虽然矩阵使线性变换能够进行计算，但为了进一步理解变换的结构，我们希望通过研究空间的各个部分来理解整体。如果一个子空间中的向量经过变换后仍属于该子空间，就可以将变换限制在其中，这样的子空间称为不变子空间。

**判断：** 从计算转向结构研究，讲清为什么需要研究部分、什么条件使部分可以独立研究。“封闭”容易与对运算封闭或拓扑闭集混淆。这里不需要补上不变性判定步骤才能使引入成立。

### 4. 依据具体对应建立关系

**原表达：** 标准正交基还使几何条件转化为简洁的矩阵条件：相应矩阵的列向量必须标准正交。

**改进：** 为了利用矩阵判定变换是否保持这些几何性质，可以选取标准正交基。由于保持内积等价于将标准正交基映为标准正交基，而基向量的像的坐标又构成表示矩阵的各列，因此这种几何条件可以转化为矩阵列向量的标准正交条件。

**判断：** 在有限维同空间变换的语境中，调用前文建立的“基向量的像的坐标构成矩阵的列”，读者由此理解为什么几何条件能转化为代数判据。只给结论或添加具体矩阵公式并不能代替这条桥梁。

### 5. 主题承接传达新的认识

**原表达：** 直和分解使投影有了明确含义。投影把空间分解具体化。

**改进：** 前面研究不变子空间时，利用空间的直和分解将整体变换转化为各部分上的变换。反过来，已有的空间直和分解也可以用来构造一种特殊的线性变换。

**判断：** 明确给定变换时分析其结构与给定空间分解时构造变换的区别和联系。原句虽通顺，却没有说出关系。不同的合理组织也可以成立，不强求全文每个主题都有这一类反转。

### 6. 精确给出关系与科学条件

**原表达：** 其特征值只可能为 0 或 1，相应的特征子空间分别与零空间、像空间相联系。正交投影既是幂等矩阵，也是 Hermite 矩阵。

**改进：** 对于非平凡投影，其像空间和核空间分别是特征值 1 和 0 对应的特征子空间。在标准正交基下，正交投影矩阵不仅幂等，而且是 Hermite 矩阵。

**判断：** “相联系”未说清具体对应；零投影或恒等投影不具有两个不同特征值。区分变换与其矩阵，保留矩阵判据的基条件。类似的专业限定应直接融入论述，而非补上一段抽象审查说明。

### 7. 说明能够做什么，避免正文安排代替认识

**原表达：** 相应的矩阵条件和求法可在正文中进一步展开。

**改进：** 已知直和两侧的基可以构造一般投影矩阵，而对于正交投影，只需要目标子空间的一组基就可以完成构造。

**判断：** 原句只报告写作计划，改进具体说明两类方法的输入条件及区别；不需要把构造公式也展开。若正文安排本身是用户要求的交付物，则可以保留安排说明。

### 8. 先明确需要解决的问题，再引入回答该问题的知识

**原表达（独立 Skill 首版第三章实际输出）：**

> **从矩阵表示到对角化。** 第二章已经说明，同一线性变换在不同基下的矩阵彼此相似。第三章进一步问：能否选一组基，使变换的作用尽可能简单？理想情形是选到一组特征向量构成的基。此时变换在每个基向量上只表现为数乘，表示矩阵便是对角矩阵。因此，矩阵可相似对角化的关键，是它能否拥有足够多的线性无关特征向量；等价地，各特征子空间能否直和生成全空间，或每个特征值的几何重数能否达到其代数重数。

**改进（用户提出认识顺序、助手润色、用户认可）：**

> **矩阵的相似对角化：** 线性变换可以用其在给定基下的矩阵来表示，而同一线性变换在不同基下的表示矩阵可能不同。因此，我们希望通过选取适当的基，使线性变换的矩阵表示尽可能简单，其中最理想的形式是对角矩阵。由于线性变换在特征向量上的作用仅表现为数乘，若能选取由特征向量构成的一组基，就可以得到对角矩阵表示。
>
> 那么，在什么条件下能够找到这样一组基呢？对于复数域上的 $n$ 阶方阵，其可相似对角化的充要条件是具有 $n$ 个线性无关的特征向量。等价地，全空间能够分解为各特征子空间的直和，或者每个特征值的几何重数均等于其代数重数。

**判断：** 原稿认识顺序基本合理，但把简化表示的目的、理想形式和实现思路压在一起，又以“因此”直接转入一系列判据。用户认为衔接不自然。前文已说明特征向量构成的基为什么能得到对角矩阵，接下来真正需要研究的是这样的基何时存在。改进稿先明确研究目的及理想形式，再利用特征向量的性质得到实现思路，并在需要进一步认识的位置提出存在性问题。几个等价判据共同回答这一问题，可以并列给出，无须逐项推导或强行串联。问题本身虽不增加数学定理，却是读者理解后续内容为何出现的必要背景。不是禁止使用“因此”或“等价地”，也不是要求每段都用问句：连接词和提问均服从实际认识的发展，不代替实质内容。

## 二、结构、段落与正文表达

### 1. 标题层次应表达实际主题关系

**原组织：** 单纯矩阵 → Jordan 标准型 → 矩阵多项式 → 化零多项式与 Cayley–Hamilton 定理 → 最小多项式（五个并列一级主题）。

**改进组织：**

- 相似对角化：基本思想、求法、条件。
- Jordan 标准型：基本思想、Jordan 块与 Jordan 矩阵、标准型及性质、求法。
- 矩阵多项式：定义及性质、Jordan 化计算、化零多项式与降阶计算、最小多项式。

**判断：** 本章以简化矩阵表示为目的，矩阵多项式计算是应用；化零多项式和最小多项式是降低矩阵多项式计算次数的研究内容，归入该主题更容易体现整体脉络。主题层次可因写作目的改变，不要求所有文稿采用三个主题。“Jordan 块补充了什么”若下文只介绍定义，则标题改为“Jordan 块与 Jordan 矩阵”更准确；若确实解释块结构的由来，问题式标题也可以成立。

### 2. 从已有认识引入新的概念（Old-to-New）

**原表达：** 在 Jordan 化计算一节之后直接写：“若非零多项式 $h(t)$ 满足 $h(A)=0$，则称它为 $A$ 的化零多项式。”

**改进：** 前面利用 Jordan 标准型简化了矩阵多项式的计算。除了利用矩阵结构，还可以考虑如何降低矩阵多项式的次数。如果矩阵 $A$ 满足某个非零多项式关系 $h(A)=0$，就可以利用该关系进行降阶计算。满足这一条件的非零多项式 $h$ 称为矩阵 $A$ 的化零多项式。

**判断：** 先建立共同的计算问题及另一种处理思路，再引入具体概念。不能因为两节连续出现，就认为读者已经理解化零多项式为何值得研究。若降阶动机已在紧邻的上文讲明，不必再次重复。

### 3. 段落围绕具体问题给出依据（Topic–Evidence–Link）

**改进示范：** 利用化零多项式进行降阶计算。对任意多项式 $g(t)$，由多项式除法有

$$g(t)=q(t)h(t)+r(t),\qquad \deg r<\deg h.$$

由于 $h(A)=0$，因此 $g(A)=r(A)$。这说明，只要找到矩阵的一个化零多项式，就可以将高次矩阵多项式转化为低次矩阵多项式进行计算。接下来需要研究如何找到化零多项式，Cayley–Hamilton 定理提供了一种通用方法。

**判断：** 当前论述目的为降阶；多项式除法及化零条件提供数学依据；结论说明实际作用，并引出尚需解决的问题。没有必要为满足段落模板另加引言、例子或重复结论。若下一部分不是寻找化零多项式，则按实际论述需要调整末句。

### 4. 专业措辞应直接说清关系

**原表达：** “特征多项式能使矩阵化零”；“链构成所需的基”。

**改进：** “矩阵的特征多项式是其化零多项式”；“选取适当的 Jordan 链，使所有链中的向量共同构成一组基”。

**判断：** 前者使用规范术语；后者明确基由链中的向量而非链本身构成，并保留选择适当链的必要条件。编辑时检查事实、条件和对象，而不只替换词语。

### 5. 补足必要认识，而不是只压缩知识（Logical Flow）

**原表达：** “同一个线性变换在不同基下对应的矩阵彼此相似。研究矩阵的相似变换，就是寻找一组基，使变换的作用尽可能容易理解和计算。”

**改进（认可正文中的概述）：** 线性变换可以用其在给定基下的矩阵来表示，而同一线性变换在不同基下的矩阵表示可能不同。因此，我们希望通过选取适当的基，使线性变换的矩阵表示尽可能简单，其中最理想的形式是对角矩阵。

**判断：** 当前任务是介绍简化矩阵表示的动机。先说明表示与基的关系，再提出选基化简的目的；不需要提前给出相似变换公式或把“研究相似变换”与“寻找一组基”等同。必要认识要完整表达，具体计算留待正文。多个主题的动机、主要思想及应用可分别成段，不为了篇幅简短而挤入一个段落。

### 6. 直接使用专业标题与表达

**原表达：** “将本章知识连起来”；“矩阵多项式与本章的结构化方法相容”；“块越大，需要的导数阶数越高”。

**改进：** “总结”；“矩阵多项式运算与矩阵的相似变换相容”；“计算 $g(J_r(\lambda))$ 需要用到多项式在该特征值处的函数值及至多 $r-1$ 阶导数”。

**判断：** 标题直接表达专业主题或文稿功能；明确具体的数学关系、对象及程度，不使用模糊的概括代替已有专业语言。
