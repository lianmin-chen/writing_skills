# Knowledge Explanation — 开发测试

用于开发评价，不是运行时参考。先观察实际使用结果，再根据具体问题调整 Skill。不以固定栏目、篇幅或范例措辞作为成功标准。

- **概念：** “我知道内积的定义，也知道基和坐标。为什么需要度量矩阵？” 应讲清一般基下的坐标内积与原空间内积的区别，以及基向量之间的内积如何确定度量矩阵。
- **原理：** “为什么线性变换由一组基向量的像唯一确定？” 应给出线性组合与线性性两项直接依据，必要时给出公式，不扩展为整章介绍。
- **同一对象、不同疑问：** 分别询问“为什么 Gram–Schmidt 要减去投影分量？”与“为什么 Gram–Schmidt 不改变张成空间？” 应选择不同的解释重点，保留必要数学条件和推理。
- **迁移：** “我知道数据库的基本读写。为什么数据库事务的隔离性有不同级别？” 应解释并发执行、隔离保证与成本之间的关系，区分一般原理和具体数据库实现，不机械套用数学范例。
- **任务边界：** 要求全章宏观脉络或完整知识总结时，不以本 Skill 替代相应任务。

观察回答是否直接解决用户疑问，解释是否准确、充分、自然，是否引入不必要的知识。若需要对照，尽量保持模型、问题、材料和运行环境相同，记录实际输出与用户反馈；不能以示例回归证明跨主题迁移。
