# Writing Skills

面向专业知识与学术写作的轻量 Agent Skills，重点是认识与论述的组织，以及已有文稿的专业编辑。

| Skill | 用途 |
| --- | --- |
| [knowledge-outline](knowledge-outline/SKILL.md) | 梳理专业知识的宏观脉络 |
| [writing-editor](writing-editor/SKILL.md) | 审查、润色或实质性修改已有文稿 |

按需使用，无强制全局流程。完整 Skill 目录包含运行指令和适用参考范例；测试文件用于开发评价。项目定位、调整依据及历史记录见 [DESIGN.md](DESIGN.md)。

writing-editor 为候选首版，实际效果待使用验证。
